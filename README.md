Este é um projeto básico com o objetivo de desenvolver e aprimorar habilidades com CSS grid.

🚀 Tecnologias Utilizadas

- HTML5
- CSS3

🎯 Conceitos de CSS Grid Praticados

Durante o desenvolvimento deste projeto, foram aplicados conceitos essenciais de Grid, como:
- grid-template-columns e grid-template-rows
- grid-gap
